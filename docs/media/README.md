# Iris v2 launch media

This directory contains the public, source-preview media package for Iris v2.
Each asset was generated locally from the repository's visual system and a
sanitized Neural Observatory capture. No cloud media service, stock artwork,
private desktop capture or JarvisOS data was used.

| Asset | Purpose | Technical profile |
|---|---|---|
| `iris-v2-readme-hero.png` | README hero | 1600 x 900 PNG |
| `iris-v2-social-preview.png` | GitHub social preview | 1280 x 640 PNG, under 1 MB |
| `iris-v2-launch-loop.mp4` | Silent source-preview loop | 1920 x 1080, 30 fps, 8 seconds, H.264 |

The on-screen graph is explicitly labelled `LOCAL REPRESENTATIVE DATA / NO
JARVIS DATA COPIED`. It demonstrates the verified read-only Second Brain
projection and the product's authority boundary; it does not claim that a
workflow, mutation or provider action ran.

See the [launch-media verification report](../execution/reports/2026-08-01-launch-media-verification.md)
for hashes and review evidence. The durable color, depth, motion and negative
constraints remain defined by [`DESIGN.md`](../../DESIGN.md).
