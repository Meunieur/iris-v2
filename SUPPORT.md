# Iris v2 Support

Iris v2 is currently a source-first developer preview. Community support is
best-effort and does not include a response-time guarantee.

## Choose the right channel

- Use **GitHub Discussions** for setup questions, architecture discussion and
  ideas that are not yet reproducible bugs.
- Use **GitHub Issues** for reproducible defects in the latest public commit.
- Follow **SECURITY.md** and GitHub private vulnerability reporting for a
  suspected security issue. Never disclose credentials, private brain content
  or raw local paths in a public issue or discussion.

Support is not provided through unsolicited private messages. Conduct reports
use the private contact published in `CODE_OF_CONDUCT.md`.

## Before requesting help

Include the minimum sanitized information needed to reproduce the behavior:

- Iris commit or version and Windows version;
- Node.js version and the command that failed;
- whether JarvisOS, Gemini or the camera was enabled;
- expected and actual behavior;
- a minimal reproduction and sanitized log excerpt.

Do not attach API keys, cookies, tokens, personal files, private Second Brain
content or an entire runtime data directory.

## Scope

The public Iris repository covers the Electron HUD, local gesture runtime,
normalized contracts and the attached Jarvis adapter. JarvisOS installation,
accounts, private data and provider credentials remain separately owned and
are not copied into Iris support reports.
